# Jeopardy Screen

A custom, data-driven Jeopardy board for events and parties.

**Play it live: [https://zettersten.github.io/jeopardy-screen/](https://zettersten.github.io/jeopardy-screen/)**

---

## How to Play

1. Open the game at the URL above on a screen everyone can see.
2. Click any dollar amount tile to reveal the clue fullscreen.
3. Click **Reveal Answer** to show the correct response.
4. Click **Close** to dismiss — the tile dims to show it's been used.
5. Repeat until all tiles are played.

## Creating a New Game

All game content is generated by AI. The authoritative creation protocol lives at:
**`.agents/skills/jeopardy-board-creator/SKILL.md`**

The skill covers:
- Archiving the current game before starting
- Mandatory web search for every factual clue (accuracy is paramount)
- Clue writing rules, difficulty ladder, answer format
- Overlap avoidance using `prior-games/INDEX.md`
- Validation before saving
- Updating the manifest and `current.json`

### Validate before committing

```sh
npm run validate:data   # checks current.json + manifest structure
npm run build
npm run lint
```

The validator reads all constraints (`columns`, `rows`, `pointValues`) from the game JSON itself — nothing is hardcoded. You can also validate any specific game file:

```sh
node scripts/validate-board-data.mjs data/games/game-hist-001-2025-12-22.json
```

### Board data format

Game data lives in `data/games/current.json`. Board dimensions are defined in the JSON — the UI adapts dynamically:

```json
{
  "id": "game-NNN-YYYY-MM-DD",
  "title": "Game Title",
  "date": "YYYY-MM-DD",
  "columns": 6,
  "rows": 5,
  "pointValues": [100, 200, 300, 400, 500],
  "categories": [
    {
      "name": "CATEGORY NAME",
      "questions": [
        { "points": 100, "question": "Clue.", "answer": "What is the answer?", "revealed": false }
      ]
    }
  ]
}
```
